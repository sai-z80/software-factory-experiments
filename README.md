# Software factory experiments

A shared home for controlled experiments on software delivery and maintenance.

Each experiment lives in its own dated folder under `experiments/`, with a report, aggregate results, public sources and limitations. Results are proposed through pull requests before review and merge.

## Experiments

No experiment report has been merged yet. See open pull requests for proposed reports.
